# Rucens

Registry of IP addresses and domains for services operating with restrictions in Russia

IP address ranges: [/bat](bat/)

Domains and CIDRs: [/dns](dns/)

Guide for Keenetic/Netcraze routers: https://help.keenetic.com/hc/ru/articles/360000925780-%D0%A1%D1%82%D0%B0%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D0%B5-%D0%BC%D0%B0%D1%80%D1%88%D1%80%D1%83%D1%82%D1%8B

The web registry defaults to DNS routing for KeeneticOS 5+, exporting domains and CIDR
ranges as a single `.txt` file. Switch to **IP routes · .bat** for the original format.
Each format shows services with a matching source list. Selections are preserved when
switching, and only services available in the active format are included in the export.
Duplicate entries are removed from the combined output.
